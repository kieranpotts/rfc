# Reject RFC

Handles the `PROPOSED` → `REJECTED` transition.

Rejects a proposed RFC and merges its document as a permanent record of
the decision.

## How to invoke

> Reject RFC

> Reject this RFC

> The RFC was not accepted

> The RFC was not approved

> Reject event sourcing for audit log

## Recommended models

A mid-tier model is sufficient for this skill. The steps are procedural, but
holding the gate in front of them requires a bit more effort.
