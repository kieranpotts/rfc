# Draft RFC

Scaffolds a new RFC proposal, ready for the user to write up.

Cuts an `rfc/<slug>` branch from `main`, prepares a fresh RFC from the
template, and opens a pull request in a draft state.

Sets the status to `DRAFT`.

## How to invoke

> Draft RFC

> New RFC

> Start an RFC

> We will adopt event sourcing for our audit log architecture - draft an RFC.

## Recommended models

A mid-tier model with strong prose output is best suited to this skill. The
scaffolding is mechanical, but framing the decision requires a bit more
effort.
